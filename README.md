## How to Play

1. The game starts with four discs in the center of the board
2. Players take turns placing discs of their color
3. When a player places a disc, all opponent discs between the new disc and existing discs of the player's color are flipped
4. The game ends when no more moves are possible
5. The player with the most discs on the board wins
